# 雑談ネタ生成プロンプト

`data/topics.json` を（再）生成するときに AI に渡す用のプロンプト。
実運用で気づいた失敗パターンを「悪い例」セクションにフィードバック済み。

カテゴリを追加したいときや、トーンを大きく変えたいときは、まずこのプロンプトを編集してから再生成すると統一感が保てます。

# 雑談ネタ生成

職場で同僚と気軽に話せる雑談ネタを **480〜530個程度** 生成してください。

## 形式

JSON 配列。各要素は `{ "id": "topic-001", "category": "...", "text": "..." }`。

- `id` は `topic-001` から連番（ゼロ埋め3桁）
- `category` は下記の17種から選択
- `text` は質問形式（「？」で終わる）

## カテゴリ（各カテゴリから概ね均等に — 現在18種）

- `tools`: キーボード/椅子/机周り/文房具などの作業道具
- `food`: コーヒー/お昼/おやつ/料理
- `hobby`: ゲーム/読書/音楽/映画/スポーツ観戦/写真
- `childhood`: 子供のころハマったもの、習い事、好きだった本やアニメ
- `travel`: 旅行先、印象に残った場所、行ってみたい場所
- `bgm`: 集中/作業中のBGM、好きなジャンル
- `season`: 季節・天気・年中行事、季節の思い出
- `lifestyle`: 日常のルーティン、暮らしの工夫、最近の気づき
- `imagination`: 「もし〜だったら」の仮定法・空想ネタ（経験差で詰まらない万能型）
- `gadget`: 日常のアプリ/家電/QOLガジェット（`tools`は作業道具に限定、こちらは日常寄り）
- `learning`: 学び・インプット習慣、最近知ったこと、勉強法、語学
- `nature`: 動物/植物/空・星/自然の風景（ペットの有無を聞く形にせず、思い出・仮定法ベースで）
- `web`: ネット文化/Webサービス/オンラインコンテンツ（`gadget`は道具としてのアプリ・機器、こちらは文化・コンテンツ寄り）
- `health`: デスクワーカーの体のケア・睡眠・運動習慣・ストレッチ（健康状態・持病・体型への言及はNG、あくまで日常の習慣・工夫ベース）
- `values`: 個人の価値観・判断基準・ものの考え方（政治・宗教・思想信条はNG、暮らしや選択にまつわるライトな哲学）
- `local`: 地元・出身地にまつわる思い出・ご当地文化・方言（出身地の評価やランキングはNG、思い出・愛着ベース）
- `blunder`: 今だから笑える"やらかし"ネタ。勘違い・誤操作・思い込み・失敗からの発見など。愚痴や恥ずかしい告白にならないよう、「結果オーライ」「そこから学んだ」方向に着地するフレーミングを意識する
- `misc`: 他カテゴリに属さない「よもやま」ネタ。五感・自己認識・言葉の面白さ・偶然・ちょっとした不思議など、系統の違う切り口で話の幅を広げる

## 制約

**絶対に触れないトピック:**

- 恋愛・結婚・パートナー・子供の有無
- 家族構成・親族関係
- 健康状態・持病・通院歴・体型・容姿・年齢
- 年収・住居・資産
- 政治・宗教・思想
- 学歴・出身校・出身地への評価
- 芸能人ゴシップ・スキャンダル
- 業務内容そのもの（守秘の問題）

**質問の作り方:**

- YES/NO で終わらない、開かれた問い
- 一人称や属性を前提にしない（「お子さんは〜」「実家では〜」NG）
- 「最近〜」「今まで〜」「もし〜」など、答えやすい時間軸を設定
- エンジニア・技術職が興味を持ちやすい話題寄り
- ただし専門知識を要求しすぎない（誰でも答えられる温度感）
- 季節イベント（クリスマス・お盆・夏休み等）に依存した質問は避ける。「この時期」のような時期固定表現も避ける
- ネガティブ方向に振れやすい問い（愚痴・恥ずかしい話のきっかけ）は避ける

## 良い例

- 「最近買って良かった作業道具は何ですか？」
- 「子供のころハマったゲームで、今でも覚えてるシーンはありますか？」
- 「集中したいときに聴くBGM、何かこだわりありますか？」
- 「写真撮るなら、何を撮りたいですか？」
- 「音楽、どんなふうに聴いてますか？」
- 「年中行事で楽しみにしてるものってありますか？」

## 悪い例（避けてほしい）

### 1. 属性前提・NGトピック

- 「ご結婚されてますか？」（属性前提）
- 「年収いくらですか？」（NGトピック）
- 「○○さん（芸能人）どう思う？」（ゴシップ）

### 2. YES/NO で答えが終わる

- 「Rustって難しいと思う？」
- 「ペット、飼ったことありますか？」（はい/いいえで終了する）
- 「クリップボード履歴ツール、使ってますか？」

→ 経験ベース・内容ベースに振る:「動物との思い出、何かありますか？」「クリップボード周り、何か工夫してますか？」

### 3. 二者択一の「○○派？△△派？」

- 「コーヒー派？紅茶派？」
- 「Mac派？Windows派？Linux派？」
- 「アウトドア派？インドア派？」

→ 答えがラベルで終わってしまい、話が広がらない。「コーヒーや紅茶、最近のお気に入りってありますか？」のように開く。

### 4. 「○○、X？／Y？」型（前半YES/NO・後半フォロー）

一見開いて見えるが、前半でYES/NOが出た時点で会話が一段落する構造。生成プロンプトの中で **何度言っても再発しやすい** パターンなので特に注意。

- 「写真好きですか？何撮るのが好き？」 → ❌
- 「駅弁好きですか？お気に入りありますか？」 → ❌
- 「プレイリスト、自分で作ったりします？どんなテーマ？」 → ❌
- 「海外の音楽、聴きますか？どんなの？」 → ❌

→ 前半を捨てて、後半だけで成立する形に統一する:

- 「写真撮るなら、何を撮りたいですか？」
- 「駅弁で印象に残ってるものってありますか？」
- 「プレイリスト、どんなテーマで作ったりしますか？」
- 「海外の音楽で印象に残ってる曲やアーティストってありますか？」

### 5. 時期依存

- 「クリスマスのこの時期、楽しみにしてることありますか？」 → 5月に出ると違和感MAX
- 「夏休みの最後の日、どんな気分でした？」 → 季節限定の質問は通年で使えない

→ 「年中行事で楽しみにしてるものってありますか？」のように汎用化する。

### 6. ネガティブ方向に振れやすい

- 「家事で正直やりたくないやつってあります？」 → 愚痴大会の入口
- 「衝動買い、最近何かしました？」 → 恥ずかしい話に振れる

→ 肯定方向で:

- 「家事で意外と好きなものってありますか？」
- 「最近の小さな贅沢って何かありますか？」

### 7. 人を選ぶ・経験差で詰まる

- 「リストレストどう思います？」 → 使ってない人「特に……」
- 「ジャズって、どんなイメージ持ってます？」 → 触れたことない人答えにくい
- 「DJミックスやライブ配信、何かハマってる番組ありますか？」 → ニッチすぎ

→ 経験ベースに振るか「もし〜するとしたら」の仮定法にする。
あるいは別の話題に置き換える。

## 出力

純粋な JSON 配列のみ。前後の説明文不要。
